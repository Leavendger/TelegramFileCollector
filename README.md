# TelegramFileCollector

批量收集并下载 Telegram 频道 / 群组中文件的工具。

> **状态：早期规划阶段。** 目录结构与公开接口尚未稳定，欢迎在 Issues 里提需求。

## 它要解决什么

Telegram 里不少频道把资源直接以文件形式堆在历史消息里，官方客户端只能一条条手动另存。本项目希望做到：

- 指定频道 / 群组 / 话题，按规则批量抓取文件
- 断点续传，任务中断后可恢复，不重复下载
- 按规则自动归档命名，落盘到本地目录

## 规划中

具体的功能边界、技术选型细节和里程碑还在梳理，确定后会补充到本文件。当前初步方向：

- 语言：Python
- 客户端库：Telethon / Pyrogram，待评估
- 分发形态：CLI 优先，配置文件驱动
